Headless workflow

PSXRecompStudio CLI

Avalonia GUIに依存せず、terminal・CI・scriptから現在の再コンパイルbuild/run経路を利用できます。

対応入力

PS-X EXEを直接指定するか、対応CHDを指定できます。CHDの場合はproduction disc解析pipelineがSYSTEM.CNFとboot PS-X EXEを解決します。解決できない入力は誤魔化さず分類済みエラーとして停止します。

コマンド

psxrecomp recompile <input.exe|input.chd> --output <dir> [--json]
psxrecomp run       <input.exe|input.chd> [--output <dir>] [--segment-budget <n>] [--report] [--json]

recompileは実行可能なgenerated-host artifactをbuildし、runはそのartifactを再buildして現在のbounded execution pathで起動します。

JSON・exit code・診断bundle

--jsonは決定論的なmachine-readable結果を出力します。exit codeは0=成功、1=入力/Toolchain/build/launcher失敗、2=guest executionが明示的な未対応境界に到達した状態です。

run --reportではprivacy-safeなdiagnostic-report.zipを生成できます。ゲーム入力本体、RAM、save data、credential、username、local absolute pathは自動収集しません。

重要な制限

artifactのbuildや起動成功は、市販タイトル全体の互換性を意味しません。実ソフトは未対応BIOS call、control-flow、Runtime hardware境界などで明示的に停止する場合があります。

詳細仕様

正確なoption、JSON schema、exit code、diagnostic bundle仕様はHeadless CLI referenceを参照してください。
