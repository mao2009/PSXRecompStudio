PS1 hardware status

PSXRecompStudio Runtime状況

現在実装済みのPS1 Runtime基盤と、まだ未完成のハードウェア挙動を分けて説明します。

実装済みの基盤

  • R3000A実行、Delay Slot、例外、COP0、割り込みの決定論的テスト。
  • Rust-backedのguest memory/MMIO、Interrupt Controller、Timer、DMA state。
  • 部分的なBIOS HLEによるBIOS-less実行。
  • Rust-owned SIO0 register、disconnected-pad応答、IRQ7。
  • Rust-owned SPU register/MMIO storage。
  • managed GPU register/VRAM、最小triangle/rectangle rasterization、決定論的FrameSnapshot。

主な未実装・未統合部分

  • GPUのproduction title execution MMIO統合、DMA2、GPU IRQ1、追加描画機能。
  • SPUのADPCM、ADSR、mixing、reverb、sound RAM transfer、host audio output、IRQ9。
  • real controller inputとmemory-card serial protocol。
  • CD-ROM command/status/FIFO、DMA3、IRQ2。
  • 実タイトルのevidenceに応じたMDEC/GTE実装。
  • 実タイトルに必要なBIOS HLE coverage拡大。

何を優先して実装しますか？

PS1 hardwareを番号順に全部作る方針ではありません。実タイトルの実行で最初に現れる未対応境界をevidenceとして確認し、汎用的なRuntime/BIOS機能として実装する方針です。

詳細設計

ARCHITECTURE.mdとRuntime Architectureに、ownership、MMIO、scheduler、GPU、SPU、SIO0、BIOSの詳細があります。
