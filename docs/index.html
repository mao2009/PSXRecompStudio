We welcome independent, critical human reviews. Specialists in PS1 BIOS and hardware, MIPS I, static recompilation, runtime integration, testing, and game preservation can contribute through a focused question, architecture review, or reproducible synthetic test—not only through large code changes.

Transparent AI use: the maintainer defines the direction, but AI coding agents are heavily used for coding, investigations, tests, documentation, and preliminary review. Automated CI is important bounded evidence, not a substitute for independent engineering review.

Current limits: Persona opening imagery comes from the OpenBIOS interpreter path. Title-screen progress, full commercial-game native AOT parity, and playable native ports remain unverified. Our proposed multi-platform plugin ecosystem is a long-term concept, not a shipped feature.

What is PSXRecompStudio?

PSXRecompStudio is an open-source research toolkit for analyzing original PlayStation software and validating static recompilation techniques. It combines PS-X EXE and supported CHD analysis, MIPS R3000A execution models, deterministic recompiler validation, runnable generated-host artifacts, and partial PS1 Runtime hardware models.

It is a research platform, not a claim of complete commercial-game compatibility. The current project can prove bounded real-ROM-derived recompilation paths and classified execution outcomes, but it does not yet turn complete commercial PS1 titles into finished native ports.

What works today

  • R3000A / MIPS I instruction modeling, decoding, memory behavior, delay-slot behavior, exceptions, interrupts, and deterministic Golden Trace validation.
  • Disc-analysis flow covering CHD input, ISO 9660 structures, PS-X EXE extraction, MIPS analysis, basic blocks, and control-flow graph extraction.
  • A synthetic MIPS recompiler vertical slice plus bounded real-ROM-derived function proofs, whole-corpus coverage reporting, deterministic host C generation, and differential validation against the interpreter.
  • Runnable generated-host artifacts and a headless psxrecomp recompile / psxrecomp run CLI with classified JSON results and privacy-safe diagnostic bundles.
  • Partial Runtime hardware support including BIOS HLE, production-reachable interrupt/timer/DMA/memory/SIO0/SPU register state, and a managed GPU model with minimal rasterization and deterministic frame snapshots.
  • Compiler-enforced architecture boundaries and a stable C ABI shared by the C# layer and the mixed C++/Rust native core.

Not yet implemented

  • End-to-end recompilation of complete commercial PlayStation 1 titles.
  • A finished runtime for native PS1 game ports.
  • Complete GPU, SPU, CD-ROM, MDEC, and GTE support.

Technology stack

C# and .NET

Domain logic, analysis, validation, tests, and managed interop code.

Avalonia

Cross-platform desktop application shell and future analysis workflows.

C++, Rust, and CMake

Native CPU, memory, and hardware-oriented components coexist behind a stable C ABI while semantics migrate incrementally to Rust.

C ABI and P/Invoke

A narrow managed/native boundary keeps C++ and Rust implementation details out of C#.
