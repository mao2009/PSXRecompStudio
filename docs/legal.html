Project policy

Legal and asset policy

PSXRecompStudio is source code for PlayStation 1 analysis and recompilation research. It does not distribute copyrighted game or firmware content.

No ROM, ISO, CHD, or BIOS distribution

The PSXRecompStudio repository does not contain PlayStation ROM images, ISO images, CHD images, BIOS or firmware images, commercial game executables, extracted game assets, or other copyrighted game data.

These files are intentionally excluded from version control. Project tooling and CI are designed to prevent accidental inclusion of prohibited binary assets.

User-supplied files

Some analysis workflows are designed to operate on files supplied by the user. Users are responsible for ensuring that any ROM, disc image, BIOS, executable, or game asset they provide to the software was obtained and is used in accordance with applicable law and license terms.

Research purpose and project scope

PSXRecompStudio explores reverse engineering, MIPS R3000A analysis, static recompilation, validation, and native porting techniques for the original PlayStation platform. The repository contains project source code, tests, documentation, and synthetic fixtures needed for that engineering work.
