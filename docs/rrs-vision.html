Future RetroRecompStudio (RRS)

A proposed open multi-platform recompilation ecosystem—not an implemented product.

Why this direction?

PSXRecompStudio begins with PS1 static recompilation and runtime research. The proposed RetroRecompStudio would establish shared contracts for independent host implementations and platform plugins, helping authorized game developers preserve more than just the ability to play a binary.

Principles

Open plugin contracts

Public specification, versioning, and conformance tests so independent platform plugins can coexist or compete.

Interoperable hosts

Third-party hosts and forks can implement compatible interfaces; no permanent lock-in to one maintainer.

Editable developer outputs

Ultimately generate traceable, editable, maintainable, and reproducibly rebuildable sources and assets for authorized developers. Static recompilation alone does not recover original source code.

Evidence, rights and community

Prioritize verifiable correctness, provenance, legally obtained inputs, and community stewardship over compatibility claims.

Still to be demonstrated

There is no complete cross-platform plugin system today, no proven general commercial-title static recompiler, and no commercial-ready editable-source reconstruction workflow. The first steps are bounded PS1 end-to-end correctness, explicit interfaces, test fixtures, and a future ABI/specification proposal.
