# PSX R3000A CPU Specification

PSX Reimplemented Studio における PSX R3000A CPU の仕様 SSOT。

## Overview

PSX は MIPS R3000A 互換の 32 ビット RISC CPU を使用する。

| Item | Value |
|------|-------|
| CPU | MIPS R3000A (LSI CW33300) |
| Clock | 33.8688 MHz |
| ISA | MIPS I |
| Endianness | Little-endian |
| Word size | 32 bits |
| Performance | 30 MIPS |
| Bus bandwidth | 132 MB/s |
| Instruction cache | 4 KB |
| Data cache | 1 KB (scratchpad) |
| FPU | None |
| Coprocessors | CP0 (System Control), CP2 (GTE) |

## Specification Layers

仕様は3つのレイヤーに分離する（[ADR-003](../adr/003-mips-isa-r3000a-psx-layering.md)）。

| Layer | Scope | Examples |
|-------|-------|----------|
| MIPS ISA | 一般的なMIPS I ISA | 3命令フォーマット、32 GPR、delay slot |
| R3000A | R3000A固有の実装 | 5段パイプライン、CP0、キャッシュ構造 |
| PSX | PSXでの実際の挙動 | メモリマップ、例外ベクトル、COP2/GTE |

## SSOT Policy

- 本ドキュメント群がCPU仕様の唯一の信頼できる情報源（SSOT）とする
- 外部資料との矛盾がある場合は、PSX実機での検証結果を優先する
- 機械可読な命令定義は `config/cpu/r3000a-instructions.yaml` を参照する
