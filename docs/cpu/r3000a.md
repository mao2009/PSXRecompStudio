# PSX R3000A CPU Specification

This document is the specification SSOT for the PSX R3000A CPU in PSX Reimplemented Studio.

## Overview

The PSX uses a 32-bit RISC CPU compatible with the MIPS R3000A.

| Item | Value |
|------|-------|
| CPU | MIPS R3000A (LSI CW33300) |
| Clock | 33.8688 MHz |
| ISA | MIPS I |
| Endianness | Little-endian |
| Word size | 32 bits |
| Performance | 30 MIPS |
| Bus bandwidth | 132 MB/s |
| Instruction cache | 4 KB |
| Data cache | 1 KB (scratchpad) |
| FPU | None |
| Coprocessors | CP0 (System Control), CP2 (GTE) |

## Specification Layers

The specification is separated into three layers (see [ADR-003](../adr/003-mips-isa-r3000a-psx-layering.md)).

| Layer | Scope | Examples |
|-------|-------|----------|
| MIPS ISA | General MIPS I ISA | Three instruction formats, 32 GPRs, delay slots |
| R3000A | R3000A-specific implementation details | Five-stage pipeline, CP0, cache structure |
| PSX | Actual behavior on the PSX | Memory map, exception vectors, COP2/GTE |
