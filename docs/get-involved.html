Project mission

Three first contributions

Choose one small, reproducible task. Japanese-language Issues and questions are welcome; there is no need to submit a large patch.

  1. MIPS instruction check: run or inspect an existing synthetic instruction test and report expected versus observed register or memory values.
  2. BIOS/HLE test: compare one BIOS behavior with a public specification and propose a synthetic regression test. Do not upload proprietary firmware.
  3. CLI documentation: follow the CLI guide on Linux or Windows and point out incorrect commands, missing steps, or troubleshooting gaps.

Start small

  1. Read a focused Issue and check for an existing PR.
  2. Describe one concrete concern with expected behavior, observed results, and a public reference or synthetic reproduction.
  3. Offer a review, documentation correction, small test, or scoped PR after checking CONTRIBUTING.md.

Transparent AI development

The independent maintainer sets project direction. AI coding agents are used extensively for implementation, debugging, test creation, docs, and preliminary review. Automated tests are bounded evidence, not independent human validation. We welcome critical technical feedback; no one is asked to review large AI-generated changes without an agreed scope. Contributors should be transparent about AI assistance and remain accountable for tests and provenance.

Verification and legal boundaries

Persona opening screenshots demonstrate limited OpenBIOS interpreter execution—not title-screen success, complete-game recompilation, or native AOT parity. Read current verification status.

Please never upload proprietary ROMs, disc images, BIOS files, keys, or commercial game assets. Prefer synthetic distributable fixtures.
